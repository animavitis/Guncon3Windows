#guncon buttons and trigger mapping
#format is [device].[command]=[guncommand]
#device can be KEYBOARD or MOUSE
#keyboard command must be the keycode. Run program with [keys] argument to display suported keycodes
#mouse command can be Left, Right, Middle
#guncommand can be Trigger, A1, A2, B1, B2, C1, C2, AClick, BClick,
#  left stick:  LUp, LDown, LLeft, LRight
#  right stick: RUp, RDown, RLeft, RRight
#  depth axis:  ZLow (nearer than the threshold), ZHigh (further than it)
#ZLow and ZHigh split at settings.txt's ZThreshold, with a dead band either side of it.
#Read the live Z beside the bar on the Test Input tab and set the threshold from it.
#names are case-insensitive on both sides of the '='
#any line that cannot be understood is reported on startup with its line number
